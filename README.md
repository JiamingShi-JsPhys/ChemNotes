# General Chemistry — Notes

All-English lecture notes (General Chemistry) by Jiaming Shi, typeset in LaTeX.

| | |
|---|---|
| Document class | `chemistry` (custom, based on `article`; no `ctex`; all-English) |
| Engine | **XeLaTeX** (required by `unicode-math` + OpenType math font) |
| Packages | `chemfig`, `pgfplots`, `siunitx`, `amsthm`, `tikz`, ... |
| Author | Jiaming Shi — Department of Physics, Westlake University |
| Contact | jiamingshi_phys@outlook.com |

## Layout

```
General_Chemistry.tex     # main file: front matter + \input the 7 chapters
chemistry.cls             # shared class: loads all packages, fonts, theorem boxes
chapters/
  chap01.tex              # 1 Chemical Thermodynamics
  chap02.tex              # 2 Redox Reactions and Electrochemistry
  chap03.tex              # 3 Chemical Kinetics
  chap04.tex              # 4 Atomic Structure and Chemical Bonding
  chap05.tex              # 5 Crystal Structure
  chap06.tex              # 6 Coordination Compound
  chap07.tex              # 7 Advanced Topics
build/                    # CI / local build artifacts (gitignored)
```

No PDF is committed to the repository. The compiled
`General_Chemistry.pdf` is generated by GitHub Actions on every push to `main`
and attached to the Release it is built on — so each released version has
exactly one PDF, and the repo itself stays source-only.

The shared preamble lives in `chemistry.cls`; each chapter only contains
`\section`-level content. To add a note, drop a new file in `chapters/` and add
one `\input{chapters/chapNN}` line to the main file.

## Build

Locally (run from this directory so `chemistry.cls` and `chapters/` resolve):

```bash
latexmk -xelatex -interaction=nonstopmode -file-line-error -output-directory=build General_Chemistry.tex
```

On every push to `main`, GitHub Actions compiles with XeLaTeX and attaches
`General_Chemistry.pdf` to the **latest** Release (see `.github/workflows/build.yml`).
The workflow passes `-cp .` so the class and chapter files are found regardless
of the output directory.

## Fonts

`chemistry.cls` picks fonts conditionally so the same source builds locally and on CI:

- **Local (Windows):** Times New Roman / Arial
- **CI (TeX Live):** TeX Gyre Termes / TeX Gyre Heros (auto fallback, no extra install)
