# General Chemistry Notes v1

## Problem solved

Lecture notes are usually scattered across slides, PDFs and hand-written
scrap paper. This repository gives them one stable, versioned home:
self-contained LaTeX source that compiles to a single, print-quality PDF, with
a clear way to report typos and equation errors back.

## What is in this release

A self-contained set of all-English General Chemistry notes (Chapters 1--7)
plus a shareable build pipeline. The repository carries only the source and
the tooling; the compiled PDF is generated by CI and attached to this Release,
so each version of the notes has exactly one PDF here.

Highlights:

- **Seven chapters.** Thermodynamics, redox / electrochemistry, kinetics,
  atomic structure & chemical bonding, crystal structure, coordination
  compounds, and advanced topics.
- **One custom class.** All macros, fonts and theorem boxes live in
  `chemistry.cls`; chapters carry only `\section`-level content.
- **PDF only in Releases.** No PDF is committed to the repo; CI builds it on
  every push to `main` and attaches it here.
- **Portable fonts.** The class selects fonts conditionally, so the same
  source builds on Windows (Times New Roman / Arial) and on CI / Linux
  (TeX Gyre Termes / Heros) with no extra font installation.
- **Auto-published.** Each push to `main` builds with XeLaTeX and attaches the
  PDF to the latest Release.
- **Report problems.** Structured issue templates guide a reporter to the
  exact subject / page.

## Verification

Compiled with XeLaTeX (`latexmk`); all seven chapters resolve through the
custom class and the PDF is produced with no missing-glyph or
undefined-environment errors. The repository layout was verified by a clean
build from scratch.

## Limitations

- Notes are **Chapters 1--3 complete, 4--7 in progress** — later sections are
  shorter and marked "to be continued".
- No license file yet; treat the content as yours until one is added.
- Font fallback assumes a full TeX Live (as provided by the CI action); a
  minimal TeX install may be missing `chemfig` / `siunitx`.

## Install

Grab the compiled `General_Chemistry.pdf` from the Assets on this Release, or
build it from source:

```bash
git clone https://github.com/JiamingShi-JsPhys/Js_chemnotes
cd Js_chemnotes
latexmk -xelatex -interaction=nonstopmode -file-line-error -output-directory=build General_Chemistry.tex
```

## Report an issue

Found a typo, a wrong equation, or the PDF will not build? Open an issue at
https://github.com/JiamingShi-JsPhys/Js_chemnotes/issues — the
template asks for the subject and the page / section.
